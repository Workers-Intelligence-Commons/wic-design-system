# Button

One action, two to four words, verb first, sentence case ("Propose a source"), cut from a sheet of paper and set in `cue`. The consumer provides `children` (the label), `onClick`, and optionally `variant`: `primary` (red) at most once per view, for what the page is for; `ink` (default) for a strong secondary; `quiet` (ink text on an ochre cut underline) for everything else. Never round the corners; an icon-only button needs an `aria-label`.
