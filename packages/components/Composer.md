# Composer

The box where a person writes the next message. One ruled box holds the text, which grows with what is written up to a third of the window, and under it a row with the controls of the next message, the italic hint that Enter sends and Shift+Enter adds a line, and the buttons. The hint takes the room the controls leave, on two lines when it must; on a narrow screen it goes under that row. The consumer provides `onSend`, which receives the trimmed text and may return a promise; the box clears once it resolves and keeps the text if it rejects. Optionally: `running` with `onStop` adds a Stop button while a reply is being written, `onCancel` adds a Cancel button (for editing a sent message, with its text in `defaultValue`), `tools` sets controls for the next message, such as a Picker of the model with `placement="above"`, at the start of the row, where a Picker drops its border until it has the pointer, and `label`, `placeholder` and `sendLabel` replace "Message", nothing and "Send". The red Send button is the view's one primary action.
