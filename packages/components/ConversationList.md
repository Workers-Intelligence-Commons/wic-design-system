# ConversationList and ConversationItem

The column of a person's conversations, newest first, the open one marked by an ochre strip. `ConversationList` is the navigation landmark (labelled "Conversations" unless `label` says otherwise) and holds `ConversationItem`s. Each item takes `title`, and optionally `current`, `running` (a running Status after the title) and `entering` (the item arrives pasted; set it on a conversation added while the list is shown). It renders a plain link to `href`, or through `link`, a function that receives the class, the current-page mark and the content and returns the application's own link element, so a router keeps its navigation. Titles are cut with an ellipsis on one line; give an untitled conversation a word such as "Untitled", never an empty item.
