# AccountField, CurrentPasswordField, NewPasswordField and SecretField

Text inputs that tell password managers what they hold, so that a manager fills a sign-in, saves a new account, and leaves everything else alone. Each one is a `TextInput` with its type and `autocomplete` fixed, which are what the managers read. Its `name`, the key of the value in a submitted form, has a default that the consumer may replace; the consumer provides the `label` and the other native props. `AccountField` is the identifier of the person's own account, an email address unless `type="text"`; on a sign-up, `creating` makes an email address ask for an email, so that managers offer the person's addresses instead of a username; a form that changes a password shows it too, read-only, so that the manager knows which login to update. `CurrentPasswordField` is the password the person signs in with. `NewPasswordField` is a password the person chooses; its `minLength` and `maxLength` also become the `passwordrules` that managers follow when they generate one. `SecretField` holds a secret that is not the person's own password, such as an API token or a password set for someone else: managers neither fill nor save it. Give each form one purpose: a sign-in has an account and a current password, a sign-up an account and a new password, a reset request an account alone.
