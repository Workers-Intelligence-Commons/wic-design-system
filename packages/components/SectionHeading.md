# SectionHeading

A section's heading in the gothic `heading`, under its credit: a few lowercase words in the italic `aside` that say how the section is played ("in this order", "kept apart on purpose"). The consumer provides `kicker`, `children` (the heading, sentence case) and optionally `level`: `2` (default) for a section, `3` for a part of one, set in `title`. The kicker is part of the heading, so screen readers read both.
